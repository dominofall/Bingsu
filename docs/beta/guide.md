# 빙수 베타 안내

빙수는 PC·브라우저용 게임을 iPhone·iPad 에서 전체화면으로, 가상 패드나 블루투스 컨트롤러로 하는 앱이에요. 아직 베타라 문제가 생길 수 있어요. 불편한 점은 꼭 알려 주세요.

## 설치

1. iPhone·iPad 에 App Store 에서 **TestFlight** 앱을 설치해요.
2. 받은 공개 링크를 열고 "베타 참여" → "설치"를 눌러요.
3. 새 빌드가 나오면 TestFlight 가 알려 줘요. 베타 빌드는 90일 뒤 만료돼요.

필요한 것: iOS·iPadOS 26 이상. 블루투스 컨트롤러는 선택이에요.

## 기본 게임 "Bingsu"

처음 열면 게임 목록에 빙수가 직접 만든 작은 게임 **Bingsu**가 하나 있어요. 인터넷 없이 돌아가니 가상 패드·컨트롤러·진동이 잘 되는지 먼저 확인해 보세요.

- **A** 를 연타해 얼음을 갈아 목표선까지 채우고, 주문서의 화살표 순서대로 **십자키·스틱**으로 토핑을 올려요(↑ 팥, → 딸기, ↓ 연유, ← 인절미).
- 얼음은 계속 녹아요. 한 그릇 낼 때마다 시간이 조금 늘고, 두 그릇마다 단계가 올라 주문이 길어져요.
- 실수 없이 빠르게 이어 내면 콤보로 점수가 커지고, 틀린 토핑이나 넘친 얼음은 콤보를 끊어요.

## 다른 게임은 직접 구해야 해요

빙수에는 기본 게임 말고는 **게임이 들어 있지 않아요.** 게임 파일은 각 제작자가 배포하는 곳에서 직접 받아 주세요. 빙수 개발자는 게임 파일을 나눠 드리지 않아요.

| 게임 종류 | 넣는 방법 | 지금 상태 |
|---|---|---|
| Electron 웹 게임 (zip 안에 `resources/app.asar`) | Files 앱에서 zip 을 길게 눌러 공유 › 빙수, 또는 게임 목록 + › zip 파일 가져오기 | 실행돼요 |
| 브라우저에서 하는 웹 게임 | + › 주소로 웹 게임 추가 › 이름과 https 주소 | 실행돼요 |
| RPG Maker XP 게임 (zip 안에 `Game.exe`, `Data/`, `mkxp.json`) | zip 가져오기 | 실행돼요 (아래 알려진 문제 참고) |
| 그 밖의 Windows 게임 | — | 지원하지 않아요 |

큰 zip 은 **+ › 주소로 zip 내려받기** 에 https 주소를 넣으면 앱이 받아서 바로 가져와요. 앱을 내려도 계속 받고, 일시정지·이어받기도 돼요.

## 조작

- **가상 패드:** 컨트롤러가 없으면 화면에 "기본" 패드(십자키 + A·B·X·Y + L·R)가 떠요. 종류는 5가지예요 — 기본 / 스틱(왼쪽 스틱 + 트리거) / Xbox 전체 / 레트로(십자키 + A·B + 셀렉트·스타트) / 한손(세로 화면, 오른손 엄지로). 일시정지 화면이나 설정 › 가상 패드 › 종류에서 바꾸고, 게임마다 따로 고를 수도 있어요. LT·RT 를 꼭 써야 하는 게임은 처음부터 스틱 패드로 열려요. iPad 에서는 L·R 이 엄지가 닿는 원호 위에 놓여요.
- **컨트롤러:** Xbox·PlayStation·MFi 패드를 블루투스로 연결하면 가상 패드가 숨어요. 여러 모드가 있는 패드(8BitDo, IINE 등)는 **Xbox 또는 PlayStation 모드**로 켜야 iPhone 이 알아봐요.
- **일시정지:** 오른쪽 위 눈송이 구슬 버튼(컨트롤러는 홈 버튼). 가로 화면은 왼쪽, 세로 화면은 아래에 패널이 열리고, 그 자리에서 패드 종류·크기·불투명도, 소리·진동, 초당 프레임·화질, 백업을 바로 바꿀 수 있어요. 패드 설정은 이 게임에만 저장되고 "모든 게임에 적용"으로 전체에 쓸 수 있어요. 패널 밖을 누르면 계속해요. 홈으로 나가도 게임은 멈춘 채 남아 있고, "게임 종료"를 눌러야 완전히 닫혀요.

## 저장 데이터

- 저장 데이터는 앱 안에만 있어요. 꺼내려면 게임 카드를 길게 눌러 이 게임 설정 › 저장 데이터 › 백업 파일 내보내기를 써요.
- PC 에서 하던 게임은 PC 쪽 "백업 파일 내보내기"로 만든 파일을 옮긴 뒤, 게임 카드를 길게 눌러 이 게임 설정 › 저장 데이터 › PC 백업 가져오기로 이어 할 수 있어요.
- iPhone·iPad 끼리 이어하려면 설정 › 클라우드 동기화에서 **iCloud** 나 **Google Drive** 중 하나를 골라요(한 번에 하나). 두 기기 모두에서 진행했다면 게임을 열 때 어느 쪽으로 할지 물어보고, 고르지 않은 쪽은 백업으로 남아요.
  - **iCloud:** 같은 Apple ID 로 로그인된 기기끼리 따로 할 일 없이 맞춰져요.
  - **Google Drive:** 각 기기에서 "Google Drive 연결"을 누르고 같은 Google 계정으로 허용해 주세요. 저장 데이터는 내 Drive 의 숨은 앱 전용 공간에 들어가 Drive 목록에는 안 보이고, 빙수 말고는 읽을 수 없어요. 개발자도 볼 수 없어요.
  - 베타 동안 Google 연결은 **7일마다 풀려요**(Google 쪽 테스트 단계라서). "Google Drive 연결이 끊겼어요"가 보이면 다시 연결해 주세요. 데이터는 그대로예요. Google 화면에 "확인되지 않은 앱"이 나오면 "고급 › 빙수(으)로 이동"을 눌러요. 미리 테스트 사용자로 알려 준 Google 계정만 연결돼요.
  - 연결을 끊으려면 같은 자리의 "연결 해제". Drive 에 남은 데이터까지 지우려면 Google Drive 웹 › 설정 › 앱 관리 › 빙수 › "숨겨진 앱 데이터 삭제".
  - 인터넷이 없을 때도 게임은 그대로 되고, 다음에 연결되면 맞춰요.
- 웹 게임의 진행은 그 사이트의 계정·저장 방식을 따라요. 빙수는 웹 게임 로그인 정보를 iCloud·Google Drive 로 옮기지 않아요.

## 알려진 문제

- **RPG Maker XP 게임은 한 번 끝내면 빙수를 완전히 닫았다 다시 열어야 또 할 수 있어요.** 게임 엔진을 같은 앱 안에서 다시 켤 수 없어서예요. 처음 켤 때 몇 초 기다려야 해요.
- 무거운 웹 게임은 오래 하면 iOS 가 메모리를 정리하면서 **게임이 처음부터 다시 뜰 수 있어요.** 다른 앱을 닫고 기기를 식히면 줄어들어요. 로컬 게임은 최대 5초 전 저장으로 돌아와요.
- 블루투스 이어폰과 블루투스 컨트롤러 진동을 같이 쓰면 **소리가 지직거릴 수 있어요.** 설정 › 게임 중 › "블루투스 이어폰일 때 진동 줄이기"가 기본으로 켜져 있어요. 그래도 깨지면 진동을 꺼 보고 알려 주세요.
- 일부 패드는 진동 세기를 켜짐·꺼짐으로만 처리해요. 빙수는 짧게 끊어 울리는 방식으로 세기를 흉내 내요.
- 웹 게임의 로그인 창 같은 일부 화면은 패드로 고를 수 없어 화면을 직접 눌러야 해요.

## 피드백 보내는 법

- 화면을 캡처하면 TestFlight 가 "베타 피드백 보내기"를 띄워요. 캡처에 바로 메모를 적어 보내 주세요.
- 앱이 꺼졌다면 다음에 열 때 TestFlight 가 충돌 보고를 보낼지 물어봐요. 보내기를 눌러 주세요.
- 적어 주면 좋은 것: 기기 모델, 게임 이름, 컨트롤러·이어폰 사용 여부, 무엇을 하다가 생겼는지.
